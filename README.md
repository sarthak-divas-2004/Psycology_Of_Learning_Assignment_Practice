🧠 Psychology of Learning – Tests

An interactive, mobile-friendly quiz website for practicing Psychology of Learning concepts through week-wise multiple-choice tests.

✨ Features

📚 Week-wise practice tests

📝 Full test covering all 140 questions

✅ True/False-only practice mode

🔀 Randomized question and answer order

📊 Instant score after submission

💡 Shows the correct answer for incorrect responses

📖 Displays the relevant week/topic for each question

🌙 Automatic light/dark mode based on system preference

📱 Responsive and mobile-friendly design

⚡ No frameworks or dependencies required

🚀 How to Use

Simply open the website and select a test:

Week-wise Test – Practice questions from a specific week

Full Test – Attempt all 140 questions

True/False Test – Practice only True/False questions

After completing a test, click Submit to view your score and review your answers.
